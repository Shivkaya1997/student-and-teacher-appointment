# Student-Teacher Appointment System

## 📌 Project Overview
The Student-Teacher Appointment System is a web-based scheduling application that allows students to book appointments with teachers. The system includes role-based access control and secure authentication.

## 🚀 Features
- Role-based login (Admin, Teacher, Student)
- Appointment booking system
- Scheduling management
- Messaging feature
- Input validation and secure authentication

## 🛠 Tech Stack
- Backend: Java, Servlets, JDBC
- Database: MySQL
- Frontend: HTML, CSS, JavaScript
- Server: Apache Tomcat

## 🎯 Key Highlights
- Implemented booking workflow
- Designed database schema
- Ensured data validation
- Applied MVC design pattern

## 📂 How to Run
1. Clone repository
2. Configure MySQL database
3. Deploy on Apache Tomcat
4. Access via browser
